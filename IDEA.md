E-Grocery ni Aling Bebang (MVC Web Application)
Overview

E-Grocery ni Aling Bebang is a simple web-based grocery system that allows a small store owner (Aling Bebang) to manage her products online while letting customers easily view available items and prices.

The system follows the MVC (Model-View-Controller) architecture to keep the application organized, scalable, and easy to maintain.

Core Concept

The platform has two main parts:

Admin Panel (for Aling Bebang)
Public Product Page (for customers)
System Features
Admin Side (Aling Bebang Dashboard)

Aling Bebang can log in and manage her store.

Features:

Login / Logout system
Add new products
Edit product details
Delete products
Set product:
Name
Price
Description
Image (optional)
Stock quantity

This ensures she has full control over what appears on her online grocery.

Customer Side (Public View)

This is the page that buyers will see.

Features:

View list of available grocery items
See product details (name, price, description)
Simple and clean layout
(Optional upgrade) Add to cart feature

No login required — customers can quickly browse products.
